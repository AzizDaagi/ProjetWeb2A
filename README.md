# Smart Nutrition

Smart Nutrition est une application web développée en PHP/MySQL sous XAMPP selon une architecture MVC.
Le projet a été réalisé dans le cadre d’un projet intégré en utilisant Git, GitHub, branches et Pull Requests pour assurer l’intégration collaborative des différents modules.

## Modules intégrés

Le projet final contient les modules suivants :

* Gestion utilisateur
* Suivi nutritionnel
* Community
* Gestion des recettes
* Recommandations nutritionnelles
* Activité sportive

## Technologies utilisées

* PHP
* MySQL
* XAMPP
* HTML / CSS / JavaScript
* Architecture MVC
* Git / GitHub

## APIs et services externes

Le projet utilise plusieurs APIs et services externes selon la configuration :

* Brevo SMTP/API
* Firebase / Google Login
* USDA FoodData Central API
* Hugging Face API
* OpenWeather API

## Structure MVC du projet

```txt
controller/

```

## Lancement du projet

1. Cloner le dépôt GitHub
2. Placer le projet dans le dossier `htdocs` de XAMPP
3. Importer la base de données MySQL
4. Configurer les accès dans les fichiers de configuration
5. Démarrer Apache et MySQL depuis XAMPP
6. Accéder au projet via :

```txt
http://localhost/Web/
```
